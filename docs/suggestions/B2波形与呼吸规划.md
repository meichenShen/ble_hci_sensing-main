可以，而且这是一个**很值得单独开一条线的新想法**。你这个思路可以概括成：

> **从 B1 的“谱域非相干融合”推进到“时域/解析信号域相干 MRC 融合”**：

这条线和 WiFi-Sleep 的 MRC-PCA、Zhuo 的方向调整 + PCA 融合是同一类思想，但你可以做成更适合 BLE CS 的版本。

# 3. 这里的“相位差”到底是什么？

需要先澄清一点：

> 这里估计的不是 2.4 GHz BLE 载波相位差，而是 **0.1–0.35 Hz 呼吸波形分量的相位差**。

也就是说，如果两个 tone 的带通呼吸波形是：

$x_1(t) \approx A_1 \cos(2\pi f_b t + \phi_1)$

$x_2(t) \approx A_2 \cos(2\pi f_b t + \phi_2)$

你想估计的是：

$\Delta \phi = \phi_2 - \phi_1$

然后把 $x_2$ 旋转或平移到和 $x_1$ 对齐。

如果只存在正反相，那么：

$\Delta \phi \in \{0, \pi\}$

这时只需要正负号校正。

但如果 amplitude、phase、I/Q 投影之间存在连续相位偏移，那么只做 $+1/-1$ 就不够，需要连续相位补偿。

# 4. 如何计算两个呼吸波形之间的相位差？

常见方法有 4 类。

------

## 方法 A：相关系数符号校正

这是最简单的版本。

对于两个已带通的波形 $x(t)$、$y(t)$，计算 Pearson 相关系数：

$\rho_{xy} = \text{corr}(x,y)$

如果：

$\rho_{xy}<0$

则令：

$y(t) \leftarrow -y(t)$

优点：

1. 简单；
2. 稳定；
3. 不会过度处理波形；
4. 适合只存在正反相的情况。

缺点：

1. 只能处理 $0$ 或 $\pi$ 的相位差；
2. 不能处理 $30^\circ$、$60^\circ$、$90^\circ$ 这类连续相位偏移。

这是 WiFi-Sleep 中 PCA sign correction 的近似思想。

------

## 方法 B：FFT / cross-spectrum 相位差

FFT 可以用，但建议不要直接比较两个信号各自 FFT phase，而应该用**互谱相位**。

假设参考波形是 $r(t)$，待对齐波形是 $x(t)$。对同一窗口做 FFT：

$R(f)=\text{FFT}(r)$

$X(f)=\text{FFT}(x)$

在呼吸主频 $f_0$ 附近计算互谱：

$C_{x,r}(f_0)=X(f_0)\overline{R(f_0)}$

则相位差为：

$\Delta \phi_{x,r} = \angle C_{x,r}(f_0)$

如果 $x$ 比参考 $r$ 超前 $\Delta \phi$，则对 $x$ 做补偿：

$x_{\text{aligned}}(t) = \Re\left\{ z_x(t)e^{-j\Delta \phi_{x,r}} \right\}$

其中 $z_x(t)$ 是 $x(t)$ 的解析信号。

实际中不建议只用一个 FFT bin，可以在 $f_0$ 附近几个 bin 做加权求和：

$C_{x,r} = \sum_{f\in \mathcal{B}_0} X(f)\overline{R(f)}$

然后：

$\Delta \phi_{x,r}=\angle C_{x,r}$

其中 $\mathcal{B}_0$ 可以是 $f_0 \pm 0.02$ Hz 或 $f_0$ 附近 1–2 个 FFT bin。

### FFT 方法优点

1. 很适合窄带呼吸信号；
2. 和你当前 B1 的频谱框架兼容；
3. 可以直接利用 B1 得到的粗略 $f_0$；
4. 计算简单。

### FFT 方法风险

1. 如果该通道主峰很弱，相位会很不稳定；
2. 如果两个通道峰值频率不一致，互谱相位没有意义；
3. 如果选到二次谐波，相位补偿会错；
4. 单 bin phase 对频谱泄漏敏感，最好用窄带互谱平均。

结论：

> **FFT 可以，但推荐用 cross-spectrum phase，而不是裸 FFT phase。**

------

## 方法 C：Hilbert 解析信号相位差

这是我最推荐你优先实现的方法。

对实信号 $x(t)$ 做 Hilbert transform，得到解析信号：

$z_x(t)=x(t)+j\mathcal{H}\{x(t)\}$

如果参考信号为 $r(t)$，解析信号为 $z_r(t)$，则相位差可以用：

$\Delta \phi_{x,r} = \angle \left( \sum_t z_x(t)\overline{z_r(t)} \right)$

然后对 $x$ 补偿：

$z_{x,\text{aligned}}(t) = z_x(t)e^{-j\Delta \phi_{x,r}}$

最终取实部：

$x_{\text{aligned}}(t)=\Re\{z_{x,\text{aligned}}(t)\}$

这个方法本质上就是在呼吸带宽内估计两个解析信号的平均相位差。

同时还可以得到一个相干性指标：

$\gamma_{x,r} = \frac{ \left|\sum_t z_x(t)\overline{z_r(t)}\right| }{ \sqrt{\sum_t |z_x(t)|^2} \sqrt{\sum_t |z_r(t)|^2} }$

$\gamma$ 越接近 1，说明两个波形越相干；越接近 0，说明相位估计越不可信。

这个 $\gamma$ 可以进一步用于降权：

$w_i = q_i \gamma_i$

其中 $q_i$ 是你原来的 $\eta\rho$、SNR 或 BNR 权重。

------

## 方法 D：互相关最大化

还可以通过互相关找时间延迟：

$\tau^\*=\arg\max_\tau \text{corr}(x(t),r(t-\tau))$

然后把时间延迟换成相位：

$\Delta \phi = 2\pi f_0 \tau^\*$

优点：

1. 直观；
2. 对周期信号有效；
3. 可用于估计真实时间延迟。

缺点：

1. 呼吸信号周期长，20 s 窗口内周期数少，互相关峰可能不稳定；
2. 延迟估计有周期模糊；
3. 对于“通道响应相位差”而言，不一定是真实时间延迟；
4. 如果真的把信号平移，会影响窗口边界。

所以互相关可以作为诊断方法，但我不建议作为第一优先级融合方法。

# 6. 一个推荐算法：B2 Coherent-MRC Waveform Fusion

我建议把你这个新想法命名为一个新分支，例如：

```text
B2: Coherent MRC Waveform Fusion
```

它可以作为 B1 之外的 waveform-first 方法。

------

## 6.1 第一级：每个模态内的 tone-level coherent MRC

对每个模态，例如 `remote_amplitudes`，有 72 个 tone：

$x_1(t),x_2(t),\dots,x_{72}(t)$

先对每个 tone 做：

```text
median
highpass
bandpass
standardization
```

然后计算质量权重，例如：

$q_i = \eta_i \rho_i$

或者更 MRC-like：

$q_i=\sqrt{\text{SNR}_i}$

其中：

$\text{SNR}_i = \frac{E_{0.1-0.35}}{E_{0.35-0.8}+\epsilon}$

选择参考 tone：

```text
reference = 质量最高的 tone
```

或者：

```text
reference = B1 per-modal fused spectrum 对应的最佳 tone
```

然后对每个 tone 估计相对于参考 tone 的相位差：

$\Delta\phi_i = \angle \left( \sum_t z_i(t)\overline{z_{\text{ref}}(t)} \right)$

对齐：

$\tilde{z}_i(t)=z_i(t)e^{-j\Delta\phi_i}$

融合：

$z_m(t) = \frac{ \sum_i q_i \gamma_i \tilde{z}_i(t) }{ \sum_i q_i \gamma_i+\epsilon }$

得到该模态的呼吸波形：

$y_m(t)=\Re\{z_m(t)\}$

这里 $m$ 表示 remote、local 或 phase。

------

## 6.2 第二级：三个模态之间的 coherent fusion

经过第一级后得到：

$y_r(t),\quad y_l(t),\quad y_p(t)$

分别对应：

```text
remote waveform
local waveform
phase waveform
```

同样做 Hilbert：

$z_r(t), z_l(t), z_p(t)$

选择参考模态：

```text
reference modal = BNR / ACF confidence / ηρ confidence 最高者
```

然后估计模态间相位差：

$\Delta\phi_m = \angle \left( \sum_t z_m(t)\overline{z_{\text{ref}}(t)} \right)$

对齐后融合：

$z_{\text{final}}(t) = \frac{ \sum_m W_m z_m(t)e^{-j\Delta\phi_m} }{ \sum_m W_m+\epsilon }$

最终呼吸波形：

$y_{\text{final}}(t)=\Re\{z_{\text{final}}(t)\}$

模态权重 $W_m$ 可以从简单到复杂：

### 版本 1：Equal

$W_r=W_l=W_p=1$

### 版本 2：质量权重

$W_m = \text{BNR}_m$

或：

$W_m = \text{ACFConf}_m$

### 版本 3：保守自适应

$W_m = (1-\lambda)\frac{1}{3} + \lambda \frac{s_m}{\sum_j s_j+\epsilon}$

这和我之前建议的 shrink-to-equal 一致。

# 7. 代码骨架：Hilbert 相位对齐融合

下面是一个最小可用的核心函数。

```python
import numpy as np
from scipy.signal import hilbert

def coherent_mrc_fuse_hilbert(
    X,
    quality,
    ref_idx=None,
    min_coherence=0.2,
    coherence_power=1.0,
    eps=1e-12,
):
    """
    Hilbert analytic-signal based coherent MRC fusion.

    Parameters
    ----------
    X : np.ndarray
        Shape [T, C]. Bandpassed real-valued waveforms.
    quality : np.ndarray
        Shape [C]. Nonnegative channel quality, e.g. eta*rho or sqrt(SNR).
    ref_idx : int or None
        Reference channel. If None, use max quality channel.
    min_coherence : float
        Channels with coherence lower than this are suppressed.
    coherence_power : float
        Final weight uses quality * coherence**coherence_power.
    eps : float
        Numerical stabilizer.

    Returns
    -------
    y : np.ndarray
        Shape [T]. Fused real-valued waveform.
    info : dict
        Phase offsets, coherence, weights, reference index.
    """
    X = np.asarray(X, dtype=float)
    quality = np.asarray(quality, dtype=float)

    T, C = X.shape

    # Remove mean per channel
    X0 = X - np.mean(X, axis=0, keepdims=True)

    # Optional: standardize each channel to avoid amplitude domination
    X0 = X0 / (np.std(X0, axis=0, keepdims=True) + eps)

    # Analytic signals
    Z = hilbert(X0, axis=0)

    if ref_idx is None:
        ref_idx = int(np.nanargmax(quality))

    z_ref = Z[:, ref_idx]

    phases = np.zeros(C)
    coherences = np.zeros(C)
    Z_aligned = np.zeros_like(Z, dtype=np.complex128)

    ref_energy = np.sum(np.abs(z_ref) ** 2)

    for i in range(C):
        zi = Z[:, i]

        # Cross analytic inner product:
        # angle = phase_i - phase_ref
        c = np.sum(zi * np.conj(z_ref))

        phases[i] = np.angle(c)

        zi_energy = np.sum(np.abs(zi) ** 2)
        coherences[i] = np.abs(c) / (np.sqrt(zi_energy * ref_energy) + eps)

        # Align channel i to reference
        Z_aligned[:, i] = zi * np.exp(-1j * phases[i])

    weights = quality.copy()
    weights = np.maximum(weights, 0.0)

    # Coherence gating
    weights = weights * (coherences ** coherence_power)
    weights[coherences < min_coherence] = 0.0

    if np.sum(weights) < eps:
        # Fallback: use reference channel
        y = np.real(Z[:, ref_idx])
        weights = np.zeros(C)
        weights[ref_idx] = 1.0
    else:
        weights = weights / (np.sum(weights) + eps)
        z_fused = Z_aligned @ weights
        y = np.real(z_fused)

    y = y - np.mean(y)
    y = y / (np.std(y) + eps)

    info = {
        "ref_idx": ref_idx,
        "phases_rad": phases,
        "phases_deg": phases * 180.0 / np.pi,
        "coherences": coherences,
        "weights": weights,
    }

    return y, info
```

这个函数可以用于：

1. 72 tone 融合成一个模态波形；
2. 3 个模态波形融合成最终波形。

# 8. FFT 相位差版本怎么写？

如果你想用 FFT，也可以这样做。关键是用互谱：

```python
import numpy as np

def estimate_phase_diff_fft(
    x,
    ref,
    fs,
    f0,
    nfft=None,
    half_width_hz=0.02,
    eps=1e-12,
):
    """
    Estimate respiratory-band phase difference between x and ref
    using cross-spectrum around f0.

    Returns
    -------
    delta : float
        Phase difference phase_x - phase_ref, in radians.
    coherence : float
        Narrowband spectral coherence-like score.
    """
    x = np.asarray(x, dtype=float)
    ref = np.asarray(ref, dtype=float)

    n = len(x)

    if nfft is None:
        nfft = 2 ** int(np.ceil(np.log2(4 * n)))

    win = np.hanning(n)

    xw = (x - np.mean(x)) * win
    rw = (ref - np.mean(ref)) * win

    X = np.fft.rfft(xw, n=nfft)
    R = np.fft.rfft(rw, n=nfft)
    freqs = np.fft.rfftfreq(nfft, d=1.0 / fs)

    mask = np.abs(freqs - f0) <= half_width_hz

    if not np.any(mask):
        k = int(np.argmin(np.abs(freqs - f0)))
        mask = np.zeros_like(freqs, dtype=bool)
        mask[k] = True

    # Cross spectrum: phase_x - phase_ref
    C = np.sum(X[mask] * np.conj(R[mask]))

    delta = np.angle(C)

    coherence = np.abs(C) / (
        np.sqrt(np.sum(np.abs(X[mask]) ** 2) * np.sum(np.abs(R[mask]) ** 2))
        + eps
    )

    return delta, coherence
```

补偿时可以继续用 Hilbert 解析信号：

```python
from scipy.signal import hilbert

delta, coh = estimate_phase_diff_fft(x, ref, fs, f0)
z = hilbert(x - np.mean(x))
x_aligned = np.real(z * np.exp(-1j * delta))
```

注意：

> FFT 负责估计相位差；Hilbert 负责在时域对实信号做连续相位旋转。

# 9. 这个方法和 MRC 的关系

如果把每个通道看成：

$z_i(t)=h_i s(t)+n_i(t)$

其中：

- $z_i(t)$：第 $i$ 个 tone 的解析信号；
- $s(t)$：潜在真实呼吸解析信号；
- $h_i$：该 tone 对呼吸的复响应；
- $n_i(t)$：噪声。

经典 MRC 的思想是：

$\hat{s}(t) = \sum_i \frac{\overline{h_i}}{\sigma_i^2} z_i(t)$

也就是：

1. 用 $\overline{h_i}$ 抵消通道相位；
2. 用 $1/\sigma_i^2$ 或 SNR 给高质量通道更大权重。

你的 BLE 版本可以近似成：

$\hat{s}(t) = \sum_i q_i e^{-j\hat{\phi_i}} z_i(t)$

其中：

- $q_i$：$\eta\rho$、BNR、SNR 或 $\sqrt{\text{SNR}}$；
- $\hat{\phi_i}$：相对于参考通道的呼吸相位差。

所以这确实是一个很自然的 **MRC-like coherent fusion**。

# 10. 需要小心的地方

## 10.1 不要一开始就强行相干融合所有通道

如果某些 tone 的相位估计不可靠，强行补偿反而会引入噪声。

建议用 coherence gating：

```text
如果 channel coherence < 0.2 或 0.3：
    不参与相干融合
```

最终权重可以设为：

$w_i=q_i\gamma_i$

或者：

$w_i=q_i\gamma_i^2$

其中 $\gamma_i$ 是与参考信号的相干性。

------

## 10.2 相位对齐最好基于共同频率 $f_0$

如果每个 tone 都用自己的峰值频率估相位，会很乱。

建议：

```text
先用 B1 或 per-modal voting 得到 coarse BPM
f0 = BPM / 60
然后所有 tone 都在这个 f0 附近估计相位差
```

这样会稳定很多。

不过这样也会带来一点“用 B1 引导新算法”的问题。解决方式是：

```text
B1 只提供粗初始化 f0
coherent fusion 后再重新估计 BPM
最多迭代一次
```

------

## 10.3 呼吸波形的“形态”不一定完全等于真实胸腹位移

三模态分别来自：

```text
remote amplitude
local amplitude
phase
```

它们对胸腹运动的响应函数可能不同。

即使相位对齐后融合，得到的也更准确地说是：

```text
latent respiratory waveform
```

而不是严格医学意义上的胸腹位移波形。

它对 BPM、周期性、相对深浅变化可能有帮助，但对吸气/呼气方向的生理解释仍然需要 ground truth。

------

## 10.4 连续相位旋转可能改变非正弦波形形态

Hilbert phase rotation 对窄带信号很自然。

但如果呼吸波形包含明显谐波、暂停、非正弦形态，那么用一个固定相位 $\Delta\phi$ 对整段波形旋转，可能会改变部分形态。

因此建议分两类评估：

```text
BPM 任务：
    phase-aware fusion 很合理

形态任务：
    先谨慎，只评估相对深度、周期稳定性，不要直接解释吸气/呼气
```

```text
→ phase compensation
→ coherent sum
```

这个版本和你当前频谱框架结合最紧。

## B2d：Two-Level Hilbert-MRC

完整版本：

```text
每个模态内部：
    72 tone → Hilbert-MRC → modal waveform

模态之间：
    3 modal waveforms → Hilbert-MRC → final waveform

final waveform:
    PSD / ACF / peak interval → BPM
```

这是最终目标版本。

------

# 12. 和目前 B1 的关系

这条线不应该替代 B1，而应该和 B1 并行。

我建议整体架构变成：

```text
B1:
    谱域非相干融合
    优点：稳、简单、BPM 强

B2:
    时域相干融合
    优点：能输出波形，可能提高困难场景 BPM

Hybrid:
    B1 给出 coarse BPM 和质量诊断
    B2 输出波形
    BPM 最终由 PSD + ACF + B1 consensus 决定
```

也就是说，B1 可以继续作为强 baseline 和 fallback。

# 13. 最推荐的下一步实验

我建议你把这个新想法加入规划，优先级甚至可以很高。具体顺序：

```text
Step 1:
    先实现 per-modal Sign-MRC
    看正负号校正后的 waveform 是否比单 tone / B1 更清晰

Step 2:
    实现 per-modal Hilbert-MRC
    只在每个模态内部融合，不做三模态相干融合

Step 3:
    比较三个模态波形的相干性
    如果 remote/local/phase 之间 coherence 高，再做 modal-level phase fusion

Step 4:
    实现 Two-Level Hilbert-MRC

Step 5:
    从 final waveform 上同时跑：
        PSD BPM
        ACF BPM
        peak-interval BPM
    和 B1 BPM 做一致性检查
```

# 14. 简短结论

你的想法是合理的，而且很有研究价值。

核心建议是：

1. **可以借鉴 MRC，但最好用解析信号做相干融合。**
2. **FFT 可以估计相位差，但要用 cross-spectrum phase，不要直接用单个信号的裸 FFT phase。**
3. **Hilbert 相位差更适合输出时域波形。**
4. **先做 sign-only，再做 continuous phase。**
5. **相位补偿一定要配合 coherence gating，避免坏通道污染。**
6. **三模态之间不要一开始强行融合，先看它们的相干性。**
7. **B1 可以作为 coarse BPM initializer 和 fallback。**

我会把这条新线命名为：

```text
B2 Coherent-MRC Waveform Fusion
```

它和当前 B1 的关系是：

```text
B1: spectrum-first, robust BPM
B2: waveform-first, coherent MRC, BPM from recovered waveform
```

如果 B2 成功，你就能更系统地说明：

> BLE CS 不仅可以通过多 tone 谱域 voting 得到稳定 BPM，也可以通过 MRC-like 相干融合恢复一条高质量的潜在呼吸波形。
